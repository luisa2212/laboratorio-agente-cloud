# Laboratorio #12 – Preguntas de reflexión

**1. ¿Qué diferencia fundamental existe entre un CLI Agent y un agente cloud?**

Un CLI Agent trabaja desde la terminal del equipo local y utiliza los recursos del entorno donde se ejecuta. En cambio, un agente cloud trabaja en un entorno remoto, permitiendo delegar tareas y continuar su ejecución sin depender de que la computadora local permanezca activa.

**2. ¿Qué parte del trabajo pudo continuar, aunque usted no estuviera ejecutando nada en su computadora?**

La implementación de las modificaciones solicitadas, el análisis del repositorio, la ejecución de pruebas y la preparación de una rama con los cambios y su Pull Request.

**3. ¿Por qué un Pull Request es una buena frontera de control entre el agente y el desarrollador?**

Porque permite revisar los cambios realizados por el agente antes de incorporarlos al proyecto principal. El desarrollador puede analizar el código, comprobar las pruebas y solicitar correcciones antes de aprobarlo.

**4. ¿Qué riesgo existiría si el agente pudiera hacer merge automáticamente sin revisión?**

Podría incorporar errores, cambios innecesarios o código que no cumpla los requisitos del proyecto, afectando su funcionamiento y mantenimiento.

**5. ¿Qué información debe contener un issue para que una tarea sea realmente delegable?**

Debe incluir un objetivo claro, el alcance de los archivos que pueden modificarse, las restricciones, los criterios de aceptación y los comandos o pruebas necesarios para validar el resultado.

**6. ¿En qué tipo de tareas usaría un agente cloud y en cuáles preferiría trabajar de forma interactiva?**

Utilizaría un agente cloud para tareas delimitadas, como agregar funcionalidades, corregir errores y crear pruebas. Preferiría trabajar de forma interactiva cuando necesite resolver problemas complejos, explorar alternativas de diseño o realizar cambios que requieran retroalimentación constante.
